## What's on the Page

A single-page personal profile introducing an IT student focused on networking and systems engineering, built with a dark, gold-accented, glassmorphism-style layout.

- **Profile header** with a photo, name, and a short introduction
- **Education & goals**, third year BSIT, expected graduation, and CCNA/network engineering aspirations
- **Technical focus areas**, Linux distributions (Kali, Arch, Ubuntu), networking fundamentals (TCP/IP, routing), and penetration testing
- **Skills matrix**, a table of networking, OS, and certification goals mapped across school years
- **Learning resources**, links out to Cisco NetAcad, Udemy, and Packt Publishing
- **Featured mini-projects**, Network Lab Setup and Linux Server Setup, each with a photo

## Tech Stack

Plain HTML5 and CSS3, single file, no frameworks or build tools. The glassmorphism look (blurred, semi-transparent panels) is done with a plain `backdrop-filter` and CSS custom properties, no library required.

## Course Context

Built as a lab activity for **WS101**, as a first pass at a personal profile page. Deployed on Netlify.
